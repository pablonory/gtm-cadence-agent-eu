## How Stage 3 uses this
- **First-touch email:** pick the one benefit that matches the account's strongest signal + persona.
  (New COO + funding + Finance → "prime-cost control / live P&L per site".)
- **Proof rule:** one proof point per message, matched to vertical AND persona. Never stack three.
- **Anti-AI gate:** benefit language runs through `context/anti_ai_writing_style.md` — no "unlock",
  "seamless", "supercharge", etc.
