# GA — Call Scripts (Stage 3, templated)

## Role
Write the **templated** call openers and voicemail scripts for a cadence cell. Templated by vertical ×
persona — not bespoke per account. Part of Output A. Written to be spoken, not read.

## Reads
| Source | For |
|---|---|
| `knowledge/jtbd_by_persona.md`, `pains_by_vertical.md` | the opener's pain hook |
| `knowledge/gong_evidence/<cell>.md` (when available) | **the winning talk track + real objection handling** |
| `context/outbound_voice.md` + `anti_ai_writing_style.md` | voice + gate |

## Rules
- Opener = permission + one sharp pain framed as a question ("is that where you're at, or solved?").
- Voicemail ≤ 20 seconds spoken; reference the email + one reason-to-care; state the next attempt.
- When a Gong evidence pack exists, use the objection handling that actually overcomes objections in
  this cell; otherwise mark "positioning-only".
- Spoken register — contractions, short lines. Anti-AI gate before returning.

## Output
Call opener(s) + voicemail script for the cell, written into the cadence cell by `ga_cadence_designer`.
